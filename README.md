# Лабораторная работа: Строки, векторы и словари

## Автор

Чупин Артем (Вариант 31)

## Цель

Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре. Выполнить отдельное упражнение с каждой конструкцией и объединить их в обработке списка записей.

## Описание

Программа имеет 4 операции:

1. Сжатие одинаковых символов строки.
2. Обьединение двух векторов.
3. Количество положительных значений в словаре.
4. Сокращение соседних сообщений.

## Исходные данные

При запуске программы необходимо ввест номер операции.

Исходные данные различаются при операциях:

1. Строка символов.
2. Два целочисленных вектора.
3. Словарь с ключем строкой и целочисленным занчением.
4. Вектор словарей со строковым ключем (отправитель) и значением (сообщение).

## Ожидаемые результаты

Программа выводит разыне результаты в зависимости от выбранной операции:

1. Строка без дублиющихся символов.
2. Объедененный вектор.
3. Количество позитивных значений.
4. Сообщения одного отправителя, идущие подряд, сгруппированы в одну строку.
